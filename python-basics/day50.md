# Day 50 - 学生表设计

## 一、先看一个你已经做过的表：`sales_data.csv`

你的 CSV 长这样：

```
date,product,quantity,price,region
2026-01-01,手机,3,2999,广州
```

它其实**已经是一张表**了。用数据库的说法写出来是这样：

| 字段名 | 类型 | 中文含义 |
|---|---|---|
| date | TEXT | 日期 |
| product | TEXT | 商品名 |
| quantity | INTEGER | 数量 |
| price | INTEGER | 单价 |
| region | TEXT | 地区 |

**对照着看三列的意思：**

- **字段名**：英文小写，程序里用的名字，就是你 CSV 的第一行
- **类型**：这一类数据是什么。整数用 `INTEGER`，文字用 `TEXT`，小数用 `REAL`
- **中文含义**：给人看的说明，随便写

## 二、现在轮到你了：学生表

**先别管格式，先别管英文。** 只回答一个问题：

> 一个「学生信息管理系统」，你需要存学生的哪些信息？

一行一个，想到几个写几个（4~8 个就行）：

- 学生姓名
- 年龄
- 学号
- 籍贯
- 身份证

---

（写完就停，把这几行发给我，我带你把它们转成上面那种表）

| 字段名 | 类型 | 中文含义 |
|--------|------|----------|
| id     | INTEGER | 编号（主键，自动递增） |
| name   |   TEXT  | 学生姓名 |
| birth_date    | TEXT  | 生日 |
| school_no | TEXT  | 学号 |
| native_place | TEXT  | 籍贯 |
| identity_card | TEXT  | 身份证 |

主键：id。理由：系统自动生成，一定存在、不会重复；学号可能还没分配。
